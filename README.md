# Claude Guard

> **VPN Guard & Multi-Account Manager для Claude Desktop на macOS**

Gatekeeper запускает **Claude Desktop** только через выбранный рабочий VPN и переключает локальные данные аккаунтов. После закрытия Claude включается второй VPN. Фоновый демон при обрыве рабочего VPN или включении любого другого VPN приостанавливает процессы Claude и возобновляет их после восстановления. Это реактивная защита: она не даёт строгой гарантии отсутствия сетевой утечки между обрывом туннеля и остановкой процессов. Для такой гарантии нужен отдельный системный сетевой барьер.

## 🚀 Основные возможности

### 1. 🛡️ Gatekeeper (проверка VPN при старте)
- Стандартный Claude Desktop при запуске начинает сетевую активность до того, как пользователь успеет включить рабочий VPN.
- **Claude Guard** заменяет точку входа в `/Applications/Claude.app` на легковесный скомпилированный Swift Gatekeeper.
- Реальный движок Claude (`Claude-Engine.app`) изолируется и **физически не запускается**, пока рабочий VPN не перейдёт в статус `Connected`, а все остальные VPN не выключатся.

### 2. ⚡️ Приостановка Claude при обрыве VPN
- Фоновый демон подписан на изменения статуса системных VPN (SystemConfiguration) и дополнительно проверяет их каждые 2 секунды.
- Если рабочий VPN не подключён или включился другой VPN, демон отправляет `SIGSTOP` процессам движка Claude. Между событием сети и обработкой сигнала возможна задержка.
- При восстановлении туннеля процесс автоматически размораживается (`pkill -CONT`) без потери несохраненных данных и открытых чатов.
- Поддерживает безопасный переход в режим сна (`willSleepNotification`) и пробуждение Mac (`didWakeNotification`).

### 3. 👥 Локальные профили Claude Desktop
- Полноценная поддержка нескольких аккаунтов на одном Mac без необходимости постоянного разлогина.
- Сессии, куки, базы данных (`Application Support/Claude`) и переключаемый файл `~/.claude.json` хранятся в отдельных папках:
  - `~/.claude-vpn-guard/profiles/<id>/`
- Обе публичные ссылки проходят через один указатель `~/.claude-vpn-guard/active`; переключение этого указателя атомарно.
- Каталог терминального Claude Code `~/.claude` остаётся общим. Работающие сеансы CLI не следует переключать одновременно с профилем Desktop.

### 4. 🎛️ Интерактивный HUD-селектор аккаунтов
- При запуске Claude открывается полупрозрачное нативное окно macOS:
  - **Автоопределение email:** считывает почту авторизованного аккаунта напрямую из сессии (включая вход через Google OAuth, Apple ID и SSO в IndexedDB).
  - **Неавторизованные слоты:** четко помечаются как `⚪️ Пустой слот`.
  - **Горячие клавиши:** `[ 1 ]`..`[ 9 ]` или `[ Enter ]` для мгновенного выбора с клавиатуры.
  - **Добавление аккаунтов (`＋ Добавить аккаунт`):** создание нового изолированного пространства в один клик с визуальным лоадером.
  - **Удаление слотов (`🗑`):** удаление ненужного профиля с обязательным подтверждением и защитой от случайного удаления активного или единственного слота.
  - **Отмена запуска:** нативный красный крестик окна или клавиша `[ Esc ]` (закрывает окно без подключения к VPN и без запуска движка).

### 5. 🔄 Автоматический переключатель VPN
- При старте Claude выключаются все VPN, кроме рабочего, и включается рабочий.
- При штатном выходе из Claude (`Cmd+Q`) рабочий VPN выключается, а VPN «без Claude» включается.
- Какой VPN рабочий, а какой включать без Claude, выбирается в окне **Настройки VPN** (см. ниже).

### 6. 🔄 Обновление и восстановление
- Установщик сначала собирает и проверяет бинарники, сохраняет копию существующего приложения и профилей, затем выполняет замену.
- После обновления официального Claude запустите `install.sh` снова. При переустановке используются существующие профили и настройки VPN.

## 🛠️ Установка

### Требования
- macOS 13.0 (Ventura) или новее (Apple Silicon или Intel; установщик собирает бинарники для текущей архитектуры).
- Установленные Command Line Tools (компилятор `swiftc`):
  ```bash
  xcode-select --install
  ```
- Установленное официальное приложение Claude Desktop в `/Applications/Claude.app`.
- Установленные VPN-клиенты с системными VPN-сервисами (видны в `scutil --nc list`).

### Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AbdulrahmanJK/claude-account-manager-guard.git
   cd claude-account-manager-guard
   ```

2. Полностью закройте Claude (`Cmd+Q`) и запустите установку. VPN можно сразу задать переменными
   (имена берутся из `scutil --nc list`) или выбрать позже в окне «Настройки VPN»:
   ```bash
   export WORK_VPN_SERVICE_NAME="<VPN для работы Claude>"
   export OTHER_VPN_SERVICE_NAME="<VPN, когда Claude закрыт>"   # необязательно
   chmod +x install.sh
   ./install.sh
   ```

Скрипт автоматически:
- Изолирует оригинальный движок Claude в защищенное хранилище `~/.claude-vpn-guard/Claude-Engine.app`.
- Скомпилирует нативный демон, Gatekeeper и утилиту проверки профилей `ProfileCtl`.
- Мигрирует текущую активную сессию в профиль `Рабочий`.
- Создаст чистый профиль `Личный`.
- Установит Gatekeeper в `/Applications/Claude.app` с оригинальной иконкой и сохранит резервную копию в `~/.claude-vpn-guard/backups/`.
- Настроит фоновую службу в `~/Library/LaunchAgents/com.user.claudevpnguard.plist`.

## ⚙️ Настройка VPN

Окно **Настройки VPN** открывается кнопкой «⚙︎ Настройки VPN» в окне выбора аккаунта или пунктом
«Настройки VPN…» в меню VPN Guard в строке меню. В нём:

- **Пока работает Claude** — рабочий VPN. Без него при включённом VPN Guard Claude не запустится.
- **Когда Claude закрыт** — VPN, который включается после выхода из Claude. «Ничего не менять» — после Claude подключения не трогаются.
- **＋ VPN из системы** — добавить системный VPN-сервис (WireGuard, IKEv2, клиенты на NetworkExtension…). Guard включает его через `scutil --nc` и проверяет реальный статус туннеля. Рекомендуемый вариант.
- **＋ Приложение…** — добавить VPN-приложение без системного сервиса. Guard только запускает и закрывает его; «включён» означает «приложение запущено», туннель не проверяется. Если у выбранного приложения есть системный сервис, окно предложит добавить его как сервис.
- Название VPN меняется двойным кликом в списке.

Пока Claude запущен, выключаются **все** остальные системные VPN, даже не добавленные в список: любой второй туннель может увести трафик Claude мимо рабочего VPN.

Настройки хранятся локально в `~/.claude-vpn-guard/vpn-config.json` (исключён из Git) и сохраняются при переустановке. Демон подхватывает их сразу после сохранения; если сменить рабочий VPN при открытом Claude, guard сам переключит туннели. При обновлении со старой версии повседневный VPN из `guard-settings.json` переносится как VPN «без Claude», а рабочий нужно выбрать в настройках.

## 🧯 Нештатные ситуации

- **Что замораживается.** Процессы `Claude-Engine.app` и все их потомки: сессии Claude Code (`~/Library/Application Support/Claude/claude-code/…`), их MCP-серверы и команды. Процессы, появившиеся уже после заморозки, догоняются на следующей проверке. Не ловятся только процессы, отцепившиеся от дерева (`nohup`, демоны, перешедшие к launchd).
- **Сон.** Перед сном Claude замораживается. Через 3,5 с после пробуждения guard выключает остальные VPN, поднимает рабочий и до 15 с ждёт; не вышло — пробует дальше в фоне с паузой 4 → 60 с, Claude остаётся замороженным, приходит уведомление. Если Claude закрыли во время пробуждения, сценарий отменяется и VPN переключается на режим без Claude. Если macOS прислала «засыпаю» без «проснулся», проверки возобновятся сами через 45 с бодрствования.
- **Быстро закрыл и открыл Claude.** Окно запуска повторяет команды VPN, пока туннель не перейдёт в нужное состояние (рабочий мог быть ещё в «отключается»). Агент не включает VPN «без Claude», пока открыто окно запуска.
- **Перезапуск или остановка агента.** `stop.sh` размораживает Claude перед выходом. После сбоя новый экземпляр сам сверяет состояние: при безопасной сети размораживает Claude, иначе замораживает заново.
- **«Закрыть Claude» в диалоге.** Guard сначала возвращает рабочий VPN, размораживает Claude и закрывает его штатно (данные сохраняются); принудительно — только если VPN не поднялся за 10 с или Claude не закрылся за 8 с. Если Claude убили, пока он был заморожен, оставшиеся замороженные процессы завершаются.
- **Claude открыли в обход окна запуска** (ссылка `claude://`, сам `Claude-Engine.app`) или **VPN Guard включили при открытом Claude** — guard сам переключает на рабочий VPN, без вопроса о закрытии.
- **Автоподключение.** Если выключенный guard'ом VPN поднимается снова, в лог и уведомление приходит подсказка отключить в его приложении On Demand / Always-on.
- **Диалог не открывается** (нет доступа ClaudeVPNGuard к System Events в «Конфиденциальность → Автоматизация») — guard возвращает рабочий VPN и сообщает об этом уведомлением.

## 🖥️ Использование

После установки открывайте Claude любым привычным способом — через **Spotlight**, **Raycast**, **Dock** или **Finder**:

1. Откроется окно выбора аккаунта:
   - Нажмите `1` или `Enter` для входа в **Рабочий** профиль.
   - Нажмите `2` для входа в **Личный** профиль.
   - Нажмите `＋ Добавить аккаунт`, чтобы создать дополнительный слот.
   - Нажмите `Esc` или красный крестик для отмены.
2. Gatekeeper выключит остальные VPN, подключит рабочий и запустит Claude.
3. По завершении работы закройте Claude через `Cmd+Q` — фоновый демон выключит рабочий VPN и включит VPN «без Claude».

### Управление через терминал

```bash
# Проверить текущий статус, активный слот и почту
~/.claude-vpn-guard/status.sh

# Смотреть лог демона в реальном времени
tail -f ~/.claude-vpn-guard/guard.log

# Перезапуск сервиса
~/.claude-vpn-guard/stop.sh
~/.claude-vpn-guard/start.sh
```

## 🧹 Удаление

Если вы решите удалить Claude Guard и вернуть Claude Desktop к стандартному состоянию:

```bash
~/.claude-vpn-guard/uninstall.sh
```

Скрипт (запускайте после полного закрытия Claude):
- Выгрузит и удалит LaunchAgent.
- Восстановит исходный `Claude.app` в `/Applications`.
- Вернёт данные рабочего профиля обратно в `~/Library/Application Support/Claude` и скопирует его `.claude.json` в домашний каталог. Личный профиль и резервные копии остаются в `~/.claude-vpn-guard`.

## Включение и отключение VPN Guard

Переключатель **VPN Guard** находится под списком аккаунтов в окне запуска Claude.
Во время работы Claude используйте пункт **VPN Guard включён / выключен** в строке меню macOS.

При выключении отключаются проверка VPN перед запуском, автоматическая смена VPN,
переподключение и процессная блокировка Claude. Уже приостановленные агентом процессы
возобновляются. Текущее VPN-соединение не меняется — им можно управлять вручную.
Выбор аккаунтов продолжает работать. При включении агент сразу проверяет работающий Claude.

Состояние сохраняется локально в `~/.claude-vpn-guard/guard-control.json`, отдельно от
настроек VPN, и сохраняется при перезапуске и переустановке. Если файл отсутствует или
повреждён, защита включена по умолчанию. `stop.sh` останавливает только агент и не заменяет
этот переключатель: проверка VPN в обёртке запуска управляется общим состоянием.
