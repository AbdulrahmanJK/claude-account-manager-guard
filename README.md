# Claude Guard

> **VPN Guard & Multi-Account Manager для Claude Desktop на macOS**

Gatekeeper запускает **Claude Desktop** после подтверждения системного VPN и переключает локальные данные аккаунтов. Фоновый демон при изменении статуса VPN приостанавливает процессы Claude и возобновляет их после восстановления соединения. Это реактивная защита: она не даёт строгой гарантии отсутствия сетевой утечки между обрывом туннеля и остановкой процессов. Для такой гарантии нужен отдельный системный сетевой барьер.

---

## 🚀 Основные возможности

### 1. 🛡️ Gatekeeper (проверка VPN при старте)
- Стандартный Claude Desktop при запуске начинает сетевую активность до того, как пользователь успеет включить защищённый VPN.
- **Claude Guard** заменяет точку входа в `/Applications/Claude.app` на легковесный скомпилированный Swift Gatekeeper.
- Реальный движок Claude (`Claude-Engine.app`) изолируется и **физически не запускается**, пока системный VPN-туннель не перейдет в подтвержденный статус `connected`.

### 2. ⚡️ Приостановка Claude при обрыве VPN
- Фоновый демон непрерывно слушает системные события `NEVPNStatusDidChange`.
- При отключении или нестабильном состоянии VPN демон отправляет `SIGSTOP` процессам движка Claude. Между событием сети и обработкой сигнала возможна задержка.
- При восстановлении туннеля процесс автоматически размораживается (`pkill -CONT`) без потери несохраненных данных и открытых чатов.
- Поддерживает безопасный переход в режим сна (`willSleepNotification`) и пробуждение Mac (`didWakeNotification`).

### 3. 👥 Локальные профили Claude Desktop
- Полноценная поддержка нескольких аккаунтов на одном Mac без необходимости постоянного разлогина.
- Сессии, куки, базы данных (`Application Support/Claude`) и переключаемый файл `~/.claude.json` хранятся в отдельных папках:
  - `~/.claude-vpn-guard/profiles/<id>/`
- Обе публичные ссылки проходят через один указатель `~/.claude-vpn-guard/active`; переключение этого указателя атомарно.
- Каталог терминального Claude Code `~/.claude` остаётся общим. Работающие сеансы CLI не следует переключать одновременно с профилем Desktop.

### 4. 🎛️ Интерактивный HUD-селектор аккаунтов
- При запуске Claude открывается полупрозрачное нативное окно macOS:
  - **Автоопределение email:** считывает почту авторизованного аккаунта напрямую из сессии (включая вход через Google OAuth, Apple ID и SSO в IndexedDB).
  - **Неавторизованные слоты:** четко помечаются как `⚪️ Пустой слот`.
  - **Горячие клавиши:** `[ 1 ]`..`[ 9 ]` или `[ Enter ]` для мгновенного выбора с клавиатуры.
  - **Добавление аккаунтов (`＋ Добавить аккаунт`):** создание нового изолированного пространства в один клик с визуальным лоадером.
  - **Удаление слотов (`🗑`):** удаление ненужного профиля с обязательным подтверждением и защитой от случайного удаления активного или единственного слота.
  - **Отмена запуска:** нативный красный крестик окна или клавиша `[ Esc ]` (закрывает окно без подключения к VPN и без запуска движка).

### 5. 🔄 Автоматический переключатель VPN
- При старте Claude автоматически отключает повседневный VPN и поднимает защищенный IKEv2 туннель.
- При штатном выходе из Claude (`Cmd+Q`) защищенный туннель выключается, а повседневный VPN автоматически возвращается.

### 6. 🔄 Обновление и восстановление
- Установщик сначала собирает и проверяет бинарники, сохраняет копию существующего приложения и профилей, затем выполняет замену.
- После обновления официального Claude запустите `install.sh` снова. При переустановке используются существующие профили и настройки VPN.

├── profiles.json          # Реестр доступных слотов аккаунтов

## 🛠️ Установка

### Требования
- macOS 13.0 (Ventura) или новее (Apple Silicon или Intel; установщик собирает бинарники для текущей архитектуры).
- Установленные Command Line Tools (компилятор `swiftc`):
  ```bash
  xcode-select --install
  ```
- Установленное официальное приложение Claude Desktop в `/Applications/Claude.app`.
- Настроенный системный VPN-профиль (IKEv2 / NetworkExtension).

### Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AbdulrahmanJK/claude-account-manager-guard.git
   cd claude-account-manager-guard
   ```

2. Для первой установки укажите имя повседневного VPN-сервиса в macOS и Bundle ID его приложения, затем запустите установку:
   ```bash
   export DEFAULT_VPN_SERVICE_NAME="<имя VPN-сервиса>"
   export DEFAULT_VPN_BUNDLE_ID="<bundle ID приложения VPN>"
   chmod +x install.sh
   ./install.sh
   ```

Скрипт автоматически:
- Изолирует оригинальный движок Claude в защищенное хранилище `~/.claude-vpn-guard/Claude-Engine.app`.
- Скомпилирует нативный демон, Gatekeeper и утилиту проверки профилей `ProfileCtl`.
- Мигрирует текущую активную сессию в профиль `Рабочий`.
- Создаст чистый профиль `Личный`.
- Установит Gatekeeper в `/Applications/Claude.app` с оригинальной иконкой и сохранит резервную копию в `~/.claude-vpn-guard/backups/`.
- Настроит фоновую службу в `~/Library/LaunchAgents/com.user.claudevpnguard.plist`.

## ⚙️ Настройка конфигурации VPN

- **Защищенный VPN:** IKEv2-соединение (управляется через системный NetworkExtension `NEVPNManager`).
- **Повседневный VPN:** соединение, управляемое через `scutil --nc` или Bundle ID приложения.

Настройки повседневного VPN хранятся только локально в `~/.claude-vpn-guard/guard-settings.json` (`defaultVpnServiceName` и `defaultVpnBundleId`), который исключён из Git. При обновлении установщик сохраняет существующий файл. Для первой установки обе переменные обязательны; названия конкретных VPN в исходниках нет. Защищённый VPN выбирается системным `NEVPNManager`.

## 🖥️ Использование

После установки открывайте Claude любым привычным способом — через **Spotlight**, **Raycast**, **Dock** или **Finder**:

1. Откроется окно выбора аккаунта:
   - Нажмите `1` или `Enter` для входа в **Рабочий** профиль.
   - Нажмите `2` для входа в **Личный** профиль.
   - Нажмите `＋ Добавить аккаунт`, чтобы создать дополнительный слот.
   - Нажмите `Esc` или красный крестик для отмены.
2. Gatekeeper подключит защищенный VPN и запустит Claude.
3. По завершении работы закройте Claude через `Cmd+Q` — фоновый демон автоматически отключит защищенный VPN и восстановит ваш повседневный туннель.

### Управление через терминал

```bash
# Проверить текущий статус, активный слот и почту
~/.claude-vpn-guard/status.sh

# Смотреть лог демона в реальном времени
tail -f ~/.claude-vpn-guard/guard.log

# Перезапуск сервиса
~/.claude-vpn-guard/stop.sh
~/.claude-vpn-guard/start.sh
```

## 🧹 Удаление

Если вы решите удалить Claude Guard и вернуть Claude Desktop к стандартному состоянию:

```bash
~/.claude-vpn-guard/uninstall.sh
```

Скрипт (запускайте после полного закрытия Claude):
- Выгрузит и удалит LaunchAgent.
- Восстановит исходный `Claude.app` в `/Applications`.
- Вернёт данные рабочего профиля обратно в `~/Library/Application Support/Claude` и скопирует его `.claude.json` в домашний каталог. Личный профиль и резервные копии остаются в `~/.claude-vpn-guard`.
